# Case Study: Using Machine Learning to Classify Skin Lesions

This case study explores how machine learning can be used to classify different types of skin lesions using dermatoscopic images and basic patient metadata. Students will investigate the challenges of building a predictive model in a real-world medical context.

## Important Information

This repository contains all materials needed to complete the case study, including:
- The case study prompt
- The deliverable instructions
- A grading rubric
- Supporting data and reference materials

## Data

The dataset used in this case study is the HAM10000 dataset, a large collection of dermatoscopic images of common pigmented skin lesions. 

Due to its size, the full dataset is not included in this repository. Students can access it here:
https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/DBW86T

The necessary metadata is located in the **Data** folder and includes:
- A cleaned metadata file for modeling

## Materials

The **Reference Materials** folder contains articles and resources that provide background on:
- Skin cancer and lesion classification
- Applications of machine learning in medical imaging
- Challenges and limitations of AI in healthcare
